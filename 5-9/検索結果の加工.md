# 検索結果の加工(演習問題)

## 問題1

### クエリ

```sql
SELECT DISTINCT department
FROM employees;
```

### 実行結果

```text
   department
----------------
 人事
 開発
 マーケティング
 営業
 IT
(5 行)
```

## 問題3

### クエリ

```sql
SELECT department FROM employees
WHERE salary >= 55000
INTERSECT
SELECT department FROM employees
WHERE hire_date >= DATE '2020-01-01';
```

### 実行結果

```text
    department
----------------
 マーケティング
(1 行)
```
---

## 問題4

### クエリ

```sql
SELECT name FROM employees
WHERE department
```

## 問題5

### クエリ

```sql
SELECT name, department
FROM employees
WHERE salary >= 50000
UNION
SELECT name, department
FROM employees
WHERE hire_date >= DATE '2020-01-01';
```
